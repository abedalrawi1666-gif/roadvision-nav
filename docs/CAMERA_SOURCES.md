# RoadVision — مصادر الكاميرا القابلة للاختيار

## الخيارات داخل التطبيق

- **كاميرا الهاتف:** اتصال بكاميرا الهاتف الخلفية عبر Flutter `camera`؛ قد تحتاج لإذن المستخدم.
- **كاميرا سيارة متصلة بالشبكة:** مصدر بث فيديو MJPEG **عبر HTTPS** من كاميرا خارجية أو وحدة ربط متوافقة. أدخل رابط البث في إعدادات الكاميرا. هذه الميزة نموذج أولي؛ لم تختبر كاميرات/شهادات/أجهزة فعلية.
- **كاميرا السيارة الأصلية:** خيار ظاهر في الشاشة لكنه **غير متصل فعلياً** بكاميرا المصنع؛ يوضح سبب عدم التوفر. يتطلب المصنع/OEM واجهة مصرحاً بها ونوع شاشة مدعوماً. لا يمكن ضمان تعميم دعم جميع العلامات والطرازات.

## طريقة اختيار المصدر

1. ادخل إلى **إعدادات الكاميرا** عبر رمز الإعدادات أعلى التطبيق، أو من وضع الكاميرا.
2. اختر **كاميرا الموبايل**، أو **كاميرا سيارة ببث شبكي**، أو **كاميرا السيارة الأصلية**.
3. إذا اخترت البث الشبكي، أدخل عنوان `https://...` يشير إلى MJPEG (`multipart/x-mixed-replace` أو `image/jpeg`). الروابط بـ HTTP وRTSP مرفوضة.
4. فعّل خيار **الرجوع إلى كاميرا الهاتف عند التعذر** إن رغبت؛ ثم اضغط **حفظ الاختيار**.
5. ادخل وضع **كاميرا الطريق** لعرض المصدر المحدد. وضع 3D مستقل عن هذا الاختيار.

## ما الذي *لا* يتوفر؟

- لا تستطيع تطبيقات الهواتف عموماً الوصول إلى الكاميرا الخلفية/الأمامية المدمجة في السيارة بمجرد اتصال Bluetooth أو Android Auto أو Apple CarPlay.
- RTSP / RTMP / H.264 غير مدعومة في العرض الشبكي الحالي.
- الفيديو الشبكي عبر شبكة محلية دون شهادة TLS صالحة غير متاح افتراضياً لتجنب طلب استثناء أمان شامل.
- كاميرات USB/UVC الموصولة بالموبايل ليست مفعلة؛ تحتاج طبقة Android USB وملحقات iOS مدعومة.
- لا يوجد تسجيل فيديو ولا تحميل بث الكاميرا إلى خادم RoadVision.
- لا توجد أسهم AR معايرة على الطريق. يلزم ضبط هندسة الكاميرا والموقع/الحركة وتقييم السلامة قبل عرضها للسائق.

## خطة توسيع الدعم

أضف `CarCameraAdapter` للمصنّعين الذين يقدمون بثاً موثقاً ومصرحاً، ثم اختبر إذن الوصول وبنية SDK لكل مصنع. أضف محولات فيديو أخرى بعد تحديد أجهزتها. لا تستخدم بيانات اعتماد الكاميرا داخل URL أو شفرة التطبيق؛ الأفضل مصادقة قصيرة العمر وتخزين آمن عند توفيرها مستقبلاً.
